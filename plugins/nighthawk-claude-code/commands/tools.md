description: Find what the connected ecosystem can do for a capability
argument-hint: <capability, e.g. "send an email" or "check spending">
---

Capability wanted: $ARGUMENTS

Run `search_tools` on the Reactor hub with two or three differently-worded
queries for the capability (by what it does, not by the user's sentence). Then
report:

- each matching `server` / `tool`, with a one-line description and the
  arguments it requires (from `input_schema`);
- which one you would use first and why;
- plainly, if nothing matches — the ecosystem has no tool for this.

Do not call any of the tools. This command only answers "can this be done, and
with what".
